Visão geral

O que é o FitTrack?

Uma PWA (Progressive Web App) para organizar treinos, exercícios e dietas em um só lugar, com instalação direta na tela inicial e funcionamento offline.

🏋️
Treinos

Planos de treino

Crie planos com exercícios, séries, repetições, cargas e duração. Filtros por nível e busca rápida.

🥗
Dietas

Planos alimentares

Defina meta diária de calorias e organize refeições com acompanhamento de progresso em porcentagem.

📱
PWA

Instalável e offline

Instale no celular ou desktop, use sem internet com dados em cache e receba atualizações automáticas.

Dashboard com IMC, peso, altura, calorias da dieta atual e treinos recentes.

Progressive Web App

Por que PWA?

⬇️
Instalação

Tela inicial

Prompt de instalação via beforeinstallprompt, atalho no sidebar e no header mobile.

📴
Offline

Funciona sem internet

Service Worker com cache de assets e dados; banner avisa quando está offline.

🔄
Atualizações

autoUpdate

Service Worker se atualiza sozinho e recarrega o app com a versão mais recente.

🎨
Aparência

Standalone

Modo standalone, ícones 192/512 px, mascarável, theme-color e splash nativo.

Tema claro, escuro e sistema, persistido em localStorage e sincronizado com prefers-color-scheme.
Primeiros passos

Como usar o FitTrack

01

Acesse

Abra o endereço do FitTrack no navegador (Chrome, Edge, Safari).

02

Cadastre

Crie sua conta, defina objetivo, peso e altura no perfil.

03

Instale

Toque em "Instalar aplicativo" no sidebar para adicionar à tela inicial.

04

Treine

Cadastre exercícios, crie seu primeiro treino e monte sua dieta com refeições.

05

Acompanhe

Veja o dashboard com IMC, calorias da dieta atual e progresso das refeições.

Comandos: npm run dev (desenvolvimento) · npm run build (produção) · npm run preview.
Destaques técnicos

Recursos implementados

🔐 Autenticação & rotas

AuthContext gerencia usuário/login; ProtectedRoute guarda as rotas; Layout resolve o título da página por rota.

💾 PWA & cache

vite-plugin-pwa com registerType autoUpdate; useInstallPrompt e useOnlineStatus no Layout; banner de modo offline.

🎨 Tema

ThemeProvider com localStorage, matchMedia system e meta theme-color ajustado dinamicamente.

const pwa = VitePWA({
  registerType: 'autoUpdate',
  manifest: {
    name: 'FitTrack — Treino & Nutrição',
    display: 'standalone',
    start_url: '/',
    icons: [{ src: 'pwa-192x192.png', sizes: '192x192' },
            { src: 'pwa-512x512.png', sizes: '512x512' }]
  }
});
Rotas: /inicio, /treinos, /treinos/:id, /dietas, /dietas/:id, /exercicios, /perfil, /usuarios.
